# Сезонный трек «Свой ориентир»

Запуск (нужен Node.js 18+):

    npm install
    npm run dev      # режим разработки, откроется в браузере
    npm run build    # production-сборка в папку dist
    npm run preview  # локальный просмотр production-сборки

Картинки лежат в `src/assets/`, разметка — в `src/App.jsx`, стили — в `src/styles.css`.

## Размещение на GitHub Pages
Workflow `.github/workflows/deploy.yml` собирает и публикует сайт при push в `main` или `master` (или вручную через Actions). В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника публикации.

Сборка автоматически использует путь репозитория, поэтому сайт корректно работает и в подпапке `https://<владелец>.github.io/<репозиторий>/`, и на персональном домене `https://<владелец>.github.io/`.

## Шрифты
- **Tilda Sans VF** (Bold) — файл `public/fonts/TildaSans-VF.woff2` уже в проекте. Им набраны: шапка, заголовки разделов, заголовки окон-папок, цены и кнопки в тарифах, плашка с подарком.
- **Balsamiq Sans** (Bold) подключён через Google Fonts (`index.html`). Им набраны: подписи на папках, буквы глоссария, названия и описания тарифов, 3D-буква в окне.
- Размеры выровнены свойством `font-size-adjust: .47` в `src/styles.css` (это высота строчных букв Tilda): Balsamiq автоматически подгоняется под неё.
- Шрифты меняются в `src/styles.css` (переменные `--font-main`, `--font-accent`).

## Тексты окон
Содержимое разделов и терминов глоссария — в `src/content.js`.

## Форма записи
Кнопка «Записаться» открывает форму. Отправка — в `src/api.js`: создайте файл `.env` со строкой
`VITE_ENROLL_URL=https://адрес-вашего-обработчика` (получает POST с JSON). Пока адрес не задан, заявка только выводится в консоль.
Цвета папок-окон — в `src/content.js` (`COLORS`).
